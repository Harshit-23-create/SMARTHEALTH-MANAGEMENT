## 🔗 Key Dependency Flow

```
main.jsx
  └── ThemeProvider (ThemeContext.jsx)
        └── NotificationProvider (NotificationContext.jsx)
              └── App.jsx
                    ├── QueryClientProvider (TanStack Query)
                    ├── TooltipProvider (Radix)
                    ├── Toaster, Sonner
                    └── Routes
                          ├── /login → LoginPage.jsx
                          │     └── fetch(API_BASE_URL + '/login')
                          ├── /register → RegisterPage.jsx
                          │     └── fetch(API_BASE_URL + '/register')
                          └── ProtectedRoute → DashboardLayout.jsx
                                ├── /patients → PatientManagementPage.jsx
                                │     ├── fetch(API_BASE_URL + '/patients') [GET]
                                │     ├── fetch(API_BASE_URL + '/patients') [POST]
                                │     └── fetch(API_BASE_URL + '/patients/:id') [DELETE]
                                ├── /ambulance → AmbulancePage.jsx
                                │     └── LiveMap.jsx
                                │           └── fetch(API_BASE_URL + '/ambulance-location') [poll]
                                └── All other pages → local mock data
```

## 🌍 Environment Variables

### Backend (.env)
```
MONGO_URI=mongodb+srv://...    # MongoDB Atlas URI (or localhost)
JWT_SECRET=your-secret-key     # Used to sign/verify JWTs
PORT=5000                      # Server port (default 5000)
FRONTEND_URL=https://...       # Allowed CORS origins (comma-separated)
```

### Frontend (.env.example)
```
VITE_API_URL=https://your-backend.render.com  # Backend URL
```

## 🚀 Startup Commands

```bash
# Backend
cd "CareFlow Dashboard/backend"
npm install
npm run dev          # nodemon server.js (port 5000)

# Frontend
cd "CareFlow Dashboard/careflow-dashboard"
npm install
npm run dev          # vite dev server (port 5173)

# Seed demo users (only needed once)
cd "CareFlow Dashboard/backend"
node seed.js
```
